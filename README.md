# Heroes of Might and Magic III — Browser Edition

Браузерная версия пошаговой стратегии Heroes of Might and Magic III.  
Проект студентов МВЕК (команда: 3 человека).
<img width="878" height="881" alt="image" src="https://github.com/user-attachments/assets/5c141a08-5728-47b4-b940-c6bf5c295240" >

## Стек технологий

- **Frontend**: JavaScript (83% проекта), HTML, CSS
- **Backend**: PHP
- **База данных**: SQL

---

## Что уже реализовано

- Пошаговая логика ходов (проверка правил, очки движения, допустимые действия)
- Отрисовка игровой карты и юнитов

---

### Клиент (браузер, JS)
Отвечает за всё, что видит и делает игрок:
- отрисовка карты (Canvas/DOM) и интерфейса;
- обработка кликов, проверка правил хода;
- обновление экрана.
